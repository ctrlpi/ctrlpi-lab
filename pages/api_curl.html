API - cURL Examples

Examples use the current API URL and key from the header. All endpoints except /hello require the Api-Key header.

1. Health check

Ping the Pi - no auth required. Used for discovery.

2. Read all configured pins

Returns a dict of every pin that has been configured, with its current value and settings.

3. Write to a pin

Set GPIO 26 HIGH for 2 seconds, then auto-revert. Pass "value": 0 (or "off") to set LOW, or "value": "toggle" to flip it.

4. Configure a pin (relay, reversed, max 1 hour)

Name GPIO 26 "relay", set it as a reversed output with a 1-hour max pulse duration.

5. Scan all BCM GPIO hardware pins (Pi only)

Read the physical state of the Pi’s BCM GPIO pins (requires Pi hardware). Returns level (physical) and value (logical, reversed-aware) for each pin.

6. Configure a watched input

Set GPIO 6 as a watched input. State changes send webhooks when a target is configured; with no webhook or bridge target, events are logged instead.

7. Change the webhook URL

Update where watched-pin events get POSTed.

8. Configure a sensor

Configure cpu_temp using cpu-temp.sh, the example seeded into scripts/ by the Pi installer. On a Pico, use cpu-temp.py instead.

9. Read a sensor

Read the configured sensor. The result is returned under its name, for example {"cpu_temp": 47.8}.
